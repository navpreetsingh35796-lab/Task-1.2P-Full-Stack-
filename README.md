# DEV@Deakin - Welcome Email Feature (Task P2)

A simple web app for DEV@Deakin that lets users enter their email to subscribe to the newsletter, which triggers a welcome email via SendGrid.

## Tech Stack
* **Frontend:** HTML, CSS, JavaScript (Fetch API)
* **Backend:** Node.js, Express
* **Email Service:** SendGrid API
* **Config:** dotenv
